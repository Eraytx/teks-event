- **Canlı Geri Sayım**: 8 Ekim Perşembe 18:00'e kadar sayaç.
- **Akıllı Form Doğrulama**: Ad, Soyad, Cinsiyet, Telefon Maskesi (`05XX XXX XX XX`), Üniversite Hızlı Seçim Butonları ve Bölüm.
